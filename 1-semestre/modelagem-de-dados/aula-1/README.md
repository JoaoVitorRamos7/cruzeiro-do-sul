## 1. Criação do primeiro computador

Os primeiros computadores foram criados com o objetivo de realizar cálculos e processar informações de maneira mais rápida e eficiente.

Um dos primeiros computadores eletrônicos de grande escala foi o **ENIAC**, desenvolvido na década de 1940. Ele ocupava uma grande área física e utilizava milhares de válvulas eletrônicas para realizar seus cálculos.

Com o avanço da tecnologia, os computadores foram evoluindo, tornando-se menores, mais rápidos, eficientes e acessíveis.

## 2. IBM - Primeiros computadores

A **IBM (International Business Machines)** foi uma das empresas que tiveram grande importância no desenvolvimento e na popularização dos computadores.

A empresa começou trabalhando com máquinas de processamento de dados e, posteriormente, passou a desenvolver computadores para uso empresarial.

Os computadores da IBM ajudaram a popularizar o uso da computação em empresas, principalmente para armazenamento e processamento de grandes quantidades de informações.

## 3. Analogia de Back-end e Front-end

O **Front-end** é a parte de um sistema que o usuário consegue visualizar e interagir. Ele envolve elementos como telas, botões, menus e formulários.

O **Back-end** é a parte responsável pelo funcionamento interno do sistema. Ele trabalha com regras de negócio, processamento de informações, servidores e comunicação com o banco de dados.

Uma forma simples de entender essa diferença é através da analogia de um restaurante:

- **Front-end:** o salão, o cardápio e o garçom, que representam a parte visível para o cliente.
- **Back-end:** a cozinha, onde os pedidos são processados e preparados.
- **Banco de dados:** onde ficam armazenadas as informações necessárias para o funcionamento do sistema.

## 4. Bancos SQL mais utilizados no mundo corporativo

Os bancos de dados SQL são utilizados para armazenar, organizar e consultar informações de forma estruturada.

Entre os principais bancos SQL utilizados no ambiente corporativo estão:

- **Oracle Database**
- **Microsoft SQL Server**
- **MySQL**
- **PostgreSQL**

Esses bancos utilizam a linguagem **SQL (Structured Query Language)** para realizar operações sobre os dados, como inserir, consultar, atualizar e excluir informações.

A escolha do banco de dados depende das necessidades do projeto, da infraestrutura, dos recursos necessários e dos custos envolvidos.
